# 📊 Student Performance EDA using Python & Matplotlib


## Exploratory Data Analysis on Student Performance Dataset

This project performs Exploratory Data Analysis (EDA) on a real-world student performance dataset using Python, Pandas, and Matplotlib. The notebook includes dataset understanding, basic analysis, filtering, grouping, and visualization techniques.

---

# 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

---

# 📂 Dataset Features

The dataset contains:

* Gender
* Race/Ethnicity
* Parental Level of Education
* Lunch Type
* Test Preparation Course
* Math Score
* Reading Score
* Writing Score

---

# 🔍 Operations Performed

## Dataset Understanding

* Load CSV File
* View Top Rows
* Check Dataset Shape
* Check Column Names
* Check Data Types
* Missing Values Detection

## Basic Analysis

* Average Math Score
* Highest Reading Score
* Lowest Writing Score
* Top 5 Students by Math Score
* Bottom 5 Students by Reading Score

## Filtering

* Female Students Data
* Students with Math Score > 90
* Students with Reading Score < 40
* Students with Standard Lunch
* Students who Completed Test Preparation

## GroupBy Analysis

* Gender-wise Average Math Score
* Gender-wise Average Reading Score
* Lunch-wise Average Writing Score
* Parental Education-wise Average Math Score

---

# 📊 Visualizations Included

* Histogram Chart of Math Scores
* Bar Chart of Male vs Female Average Math Scores

# ▶️ How to Run

```bash
# Clone Repository
git clone https://github.com/priyanshupatel-tech/Student-Performance-EDA.git

# Open Folder
cd Student-Performance-EDA

# Install Required Libraries
pip install pandas matplotlib
```

Then run Jupyter Notebook:

```bash
jupyter notebook
```
